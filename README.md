# Pi Pocket

A fork of [TannerMidd/pi-pocket](https://github.com/TannerMidd/pi-pocket), a self-hosted, multiplayer web
app for Pi, maintained independently: it follows that project's releases and sends nothing back.

The fork adds Loop, Command Code models, a removal that deletes a session's rows, Changes across a folder
of repositories, History, and a browser page that closes when Pi's run ends. [FORK.md](FORK.md) says what
each does, where its code is, and what a sync from upstream must keep.

Install, run, and configure it as the upstream project says: [its README](https://github.com/TannerMidd/pi-pocket#readme),
[the feature tour](docs/features.md), and [the code map](docs/map.md).
